# Food Verse AI
A starter capstone web app for multimodal food intelligence: food image analysis, nutrition guidance, cooking assistant, meal planner, and visual hygiene/freshness estimates.

## Stack
- React + Vite frontend
- Python + Flask backend
- Optional Gemini API integration
- Demo mode works without an API key

## Run
See `README_Tanglish.md` for step-by-step Windows instructions.

## Safety note
AI-generated freshness and hygiene observations are not food-safety guarantees. Never rely on an image alone to decide whether food is safe to eat.
